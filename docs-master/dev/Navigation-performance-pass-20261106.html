Rapid input and remaining costs

Both revisions received 40 commit-navigation keys and 40 panel-change keys at each cadence: 25 and 100 keys per second. Final selections and displayed commits matched. After the changes, the final commit-navigation paint took about 3–4 ms after dispatch, and the final panel change with a new diff took 35–40 ms. Maximum observed queue delay was under 1 ms after the changes. A separate five-run probe switched to Files 20 ms into a full-diff load; both revisions painted the file diff in about 8–11 ms while the large read was cancelled.

The 10,000-file commit still takes about 190–210 ms to settle its diff. Returning to the commits panel refreshes the current diff in the background; after scrolling far down, that reload remains substantial. Focus changes and subsequent keys stay responsive. Selecting the top directory of the file tree loads its large aggregate diff and takes about 85 ms; selecting an individual file near the end takes about 3–4 ms.

Method, changes, and validation

Baseline cc17f93a8; measured changes 9f1880ed6 and 0b4fd190b. Optimized binaries used identical JSONL tracing at key dispatch, Screen.Show completion, and task-manager idle. Git Trace2 and 15-second CPU profiles covered the same 81-action workload. The separate extended workload adds 27 actions per revision.

Local synthetic repository, warm Git objects, built-in renderer, no external pager. Paint timing starts at the tcell key-event timestamp and ends at Screen.Show. Physical terminal delivery and presentation are outside this probe. These small local samples describe this workload.

Short cell reservations now cover text after separately colored diff prefixes. Filename escaping shares its fixed replacement table. The colored-row benchmark allocated 658 → 287 MB; an ordinary filename now allocates 0 bytes, down from 6,928.

Passed: build, unit tests, lint, full headless integration suite, and race tests for gocui, tasks, and utils. Benchmarks: BenchmarkViewWriteGitColoredDiff and BenchmarkEscapeSpecialChars.
