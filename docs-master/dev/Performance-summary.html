What changed · 78aef7584

Before. Every redraw cleared the view, then immediately painted the content over those same cells.

After. Clear the rows below the content. Paint content rows directly, preserving the cells used by unchanged wide characters.

In the separate Unicode redraw case at 160 × 48, allocations per redraw fell from 3,634 to zero. Tests cover shrinking and empty content, scrolling, wrapping, masking, and wide-character replacement.

Repository setup completed before profiling

Created and published main at upstream’s master, configured it to track upstream/master, published experiments, and set experiments as the fork’s default branch. The first twelve implementation commits were committed locally and were not pushed during the initial four profiling passes.

Validation and measurement limits

What was checked

Every pass ended with formatting, lint, build, unit tests, and the full integration suite passing.

Preparatory refactors passed formatting, lint, unit tests, and build. The initial redraw commit had focused main_view and ui integration coverage before the parser commit’s full run.

New assertions cover stale cells, search priority, Unicode, wrapping, overwrite behavior, filtered counts, selection recovery, control sequences, and subsequent buffer writes. Selected assertions were also run against the original implementations with Go overlays. Pass 5 checks all ASCII fill allocations, Unicode encoding boundaries, and clipping that preserves surrounding screen cells. Pass 6 checks batched-write parity, deferred unlock during panic recovery, concurrent screen access, and allocation-free redraws. The full gocui test package also passed with the race detector.

Live terminal captures and preserved commit text matched, with version-footer differences where the version was visible.

How to read the numbers

  • Microbenchmarks use three-run medians on Linux amd64, Intel Core i7-1370P.
  • Live profiles are single matched pairs, not statistical latency studies.
  • Allocated bytes are total allocation over an operation, not RSS or retained heap.
  • The terminal-paste marker timing had 200 ms observation resolution.
  • Repository layout, terminal size, filesystem caches, and machine load can change results.
  • The commit-tree speedup uses about 0.9 MB more temporary storage at 10,000 files.
